#Threats and scary alerts
Medium

Fear of losing an account, money or freedom is the most common hook. The message wants a reaction, not a check.

#Asks for passwords, PINs or details
High

Banks, mobile-money providers and government offices never ask for your PIN, password or one-time code by message.
